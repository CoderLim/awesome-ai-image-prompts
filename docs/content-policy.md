# Content policy

Source cases are attributed to the original author and collecting repository, with pinned source links. The GitHub gallery references upstream images; the Cloudflare public gallery rehosts only approved cases with a documented source publication basis. The prompt field preserves the text published by the source; the Markdown presentation flattens line breaks for horizontal scrolling and copying. Third-party prompts and images retain their respective owners’ rights. Inclusion, attribution and public accessibility do not establish permission for redistribution or commercial use. Unverified rights remain marked `unknown`; they are not licensed under this project's MIT license. Rights holders can request correction or removal via issues. Do not claim that examples have been independently generated or tested. No fabricated before/after examples.

Content governance metadata is generated on each build. Cases without a real prompt or image URL are withheld from the gallery, while their original records remain indexed. Exact prompt and original-post duplicates are excluded; other similarity groups are review candidates; the three review states are pending, approved and rejected. Only approved cases with a documented source publication basis enter public galleries. See [governance report](governance-report.md).

Deduplication: records sharing an original post ID or a normalized full prompt form one connected group. Keep a single representative in the canonical catalog and rendered galleries; raw source index entries remain as audit inputs, not independent catalog cases. See data/governance/deduplication.json for exclusion mappings and data/governance/canonical.json for the non-rejected unique candidate IDs. Prefix-only similarities are not automatically removed.

Gallery navigation has two groups: Image Generation and Reference Image Generation. All image-conditioned generation and editing cases share the reference gallery; original operation type and input mode remain in governance metadata. Unknown input modes remain in general generation until confirmed.
