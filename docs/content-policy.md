# Content policy

- Source index records contain metadata and links only. Attribution is not a license.
- Record original creator and post separately from collecting repository, pinned commit and anchor. Never guess missing URLs or dates.
- Original prompt examples are CC0; hand-authored SVGs are illustrative fixtures, not AI model outputs. Do not claim verification without actual runs.
- Before adding third-party prompt text or images, document permission separately for each asset. Do not hotlink third-party media by default.
- Generation, reference-based generation and editing are distinct input modes. Uncertain classification is provisional. Review potential duplicates sharing a post ID or similar prompts before merging.
- No automatic publishing of unreviewed third-party assets. Remove disputed entries promptly through a PR.
